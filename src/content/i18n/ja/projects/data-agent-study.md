## 終わったところ

- Python と、はじめて大規模モデル API がつながった日 —— 仮想環境、ターミナル、環境変数から key を読む、そして画面に出た最初の返答。
- Pandas の核 —— 読み込み、クリーニング、集計。締めの実践はコーヒーの注文データ：商品ごとの売上と平均単価を出し、整えたデータと集計表をそれぞれディスクへ書き出した。
