这条不是作品，是一条学习线。放在这儿是因为它有产出，也有结论。

目标不是会写几个分析脚本，是最后能做一个真用得上的数据分析 Agent。路线定的是：Python 与大模型 API → Pandas → SQL → 数据分析实战 → 工具调用与 Agent 架构。

## 走完的部分

- **Python 与第一次调通大模型 API** —— 虚拟环境、终端、把 key 从环境变量里读出来，跑出第一个回复。
- **Pandas 核心** —— 读取、清洗、分组聚合。结业实战是一份咖啡订单数据：算各产品的销量与均价，清洗结果和统计表分别落盘。
