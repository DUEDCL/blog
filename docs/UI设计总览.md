## 1. 站点结构与页面清单

### 1.1 路由模型

- 中文是默认语言，**不带前缀**：`/posts/foo`；英文 `/en/posts/foo`；日文 `/ja/posts/foo`。
- 根路径是「门」（起始页），正站首页在 `/home`；`/start` 由 Astro redirect 生成 meta-refresh 跳转页。

## 2. 设计语言：对开大版

### 2.1 两条材质，一条判据

| 材质 | 用途 | 视觉配方 | 允许圆角 |
| :--- | :--- | :--- | :--- |
| **纸** | 正文、条目、卡片、图、表单 | 页面底 `--paper` + 卡片 `--paper-raised` 实底 + 1px `--rule`；直角；不模糊、不投影、不上浮 | 否 |
| **玻璃** | 顶栏、下拉菜单、播放器、对话入口、灯箱 | 半透明纸底 62% + 墨色白膜 5%/8.5% + 20px 模糊/180% 饱和 + 顶部受光描边 | 是（8–999px） |

判据写在 `global.css` 顶部：**「纸不是玻璃」**。内容一旦也放进玻璃，全站会退化成六个等重的圆角矩形，层次消失（R44 的诊断）。这条判据目前有三个例外/残留：`/music` 的四张内容卡、`/admin` 的全部面板、`/tv` 的播放器（见第 11 节）。

### 2.2 版面语汇

| 语汇 | 类名 | 用法 |
| :--- | :--- | :--- |
| 刊头 | `.mast` | 首页：刊名 + 头像 + 题词 + 社交小字 |
| 报头线 | `.pressrule` | 2px 朱红 + 1px 墨线，5px 高；页面头部的「一眼是刊物」 |
| 竖排栏标 | `.vlabel` | 区块左侧竖排中文短名（2 字）；英文整词侧躺 |
| 分栏线 | `.hairline` / `border-left` | 栏与栏之间；位置由 `--gutter` 统一决定 |
| 栏目头 | `.colhead` | 竖标 + 标题 + 计数 + 「全部 →」 |
| 索引条目 | `.briefs / .brief` | 标题左、日期右、中间自适应；上下封口线 |
| 报尾 | `.site-footer` | 一道细线 + 两簇等宽小字 |

### 2.3 两个强调色的分工

| 色 | Token | 管什么 | 出现位置 |
| :--- | :--- | :--- | :--- |
| 黄铜/琥珀/荧光青 | `--seal` | **可点击**、当前项、链接 hover、焦点环 | 链接、按钮描边、标签 `#`、当前播放行 |
| 朱红/品红 | `--press` | **刊物身份**，不承担交互 | 报头线、导航游标、404 状态码、正文强调、`wip` 状态戳 |

两者同属暖色家族（夜刊 H12 与 H30），只在饱和度和用途上分开。混用会让读者去点粗体、或以为报头线能点。

### 2.4 背景的三层

1. `html` 底色 `--paper`。
2. `body::before`：三团固定径向光晕（中性白居中偏上 + 两团低饱和暖褐/青蓝），是玻璃折射的物理前提。
3. `body::after`：240px SVG 噪点，透明度 4%–6%，消掉大面积渐变的塑料感。

## 3. 设计令牌

> 唯一来源：`src/styles/global.css`（结构/字体/间距）+ `src/styles/themes.css`（颜色）。
> 共有 95 个自定义属性名；其中 5 个当前无用户（见 11.3）。

### 3.1 字体

| 角色 | 字体栈 | 加载 |
| :--- | :--- | :--- |
| 标题 `--font-display` | Fraunces Variable → Songti SC / Source Han Serif / Noto Serif CJK | 自托管 `@fontsource-variable/fraunces` |
| 正文 `--font-body` | PingFang SC → Hiragino Sans GB → Microsoft YaHei → … | 系统栈，零下载 |
| 等宽 `--font-mono` | IBM Plex Mono 400/500 → SFMono → Menlo → Consolas | 自托管两份 woff2 |

语言覆盖：

- `html[lang='en']`：正文换 `system-ui / Segoe UI / Roboto`，避免中文全角标点空隙。
- `html[lang='ja']`：标题换 `Hiragino Mincho / Yu Mincho / Noto Serif JP`，正文换 `Hiragino Sans / Yu Gothic`，修正日文汉字字形。
- 起始页另有一份逐字相同的中文栈（`--font-cn` / `--font-cn-body`），保证「门」与站内同一套字形。

**派生层**（`themes.css` 末尾，四套共用一套公式）：

- 规则线三档：`--rule` 11% / `--rule-strong` 24% / `--rule-heavy` 55%（霓虹改用荧光青）。

## 4. 布局与响应式

### 4.1 三套布局

| 布局 | 组成 | 用于 |
| :--- | :--- | :--- |
| `BaseLayout` | `<head>` + 可选 Header + `<main>` + Footer + MiniPlayer + ChatDock + ClientRouter | 所有正站页面 |
| `ListLayout` | BaseLayout + 栏目刊头（竖标/标题/计数/报头线）+ EntryCard 列表 | `/posts`、`/notes` |
| `ArticleLayout` | BaseLayout + 面包屑/标题/导语/署名行/细线 + 封面 + `.prose` + 返回 | 文章、随笔 |

`BaseLayout` 的 `width` 属性是版心开关：`page`(72) / `prose`(38) / `broad`(80) / `wide`(96)。页脚贴底靠 `body` flex 列 + `main { flex: 1 0 auto }`。

### 4.2 断点表

| 断点 | 变化 |
| :--- | :--- |
| `60rem` | `/admin` 的两栏 `.split` 塌成单列 |
| `52rem` | 首页头版两栏塌成单列（竖分栏线变横线）；音乐页歌词/曲目上下堆叠；归档年份从左侧栏移到上方；标签条目三列变「标题 + 日期/栏目」两行 |
| `46rem` | 顶栏折两行：品牌 + 三枚键一行，导航 4 列（4+3）；页头标题降到 `--text-2xl`；`/tv` 抽屉全宽、结果网格 6.6rem |
| `40rem` | 页脚两组链接纵向堆叠；`main` 上边距减半；音乐唱盘台单列居中；播放器贴底通栏；对话键抬到播放器之上；相册灯箱翻页键移到底部两角 |
| `22rem` | 音乐页四个圆键缩小、间距收紧（320px 档） |
| `max-aspect-ratio: 11/10` | 起始页切换竖屏单位 `--m`，背景取景与遮罩重排，签名块左移并让开安全区 |
| `min-width: 600px` + 竖屏 | 起始页平板档：单位取宽/高/上限三者最小，画面取景回到 44% |

### 4.3 关键比例

- 首页头版：`2.1fr : 1fr`，天沟 3×`--gutter`，分栏线画在天沟正中（右栏负 margin + 等量 padding）。
- 文章/作品：38rem 窄栏，代码块负 margin 出血 16px。
- 图库：`auto-fit minmax(17rem, 1fr)`，行高 14rem，每第 5 张跨两行。
- 名片：`auto-fit minmax(13rem, 1fr)`，6 张卡自适应 2–3 列。
- 影视：`auto-fill minmax(8.2rem, 1fr)` 海报网格，2:3 比例。

### 5.1 顶栏尺寸与状态

- 高度 3.5rem，通栏、贴顶、只留底部 1px 线；滚动后玻璃变实 + 深阴影。
- 品牌：头像 2.25rem 圆（hover 放大 1.06 + 转 -4°）、站名 19px 宋体。

## 8. 主题、语言与渐进增强

### 8.1 主题

- 默认夜刊；`localStorage.theme` 四值白名单，读不到就夜刊；**不看** `prefers-color-scheme`（四套版次映射不到明暗二选一）。

### 8.3 渐进增强

| 能力 | 降级 |

## 11. 审查发现

> 按影响排序。P1 = 会坏功能/明显破版面；P2 = 一致性或体验缺口；P3 = 卫生问题与机会。

### 11.1 P1

1. **中文专属页面上的语言切换器指向不存在的路由。**
   `Header.astro` 无条件渲染 `<LangSwitch />`；`switchPath()` 只做前缀拼接。于是在 `/tv`、`/bushu`、`/login` 上，语言菜单的 EN/JA 指向 `/en/tv`、`/ja/bushu` 等未生成页面（构建产物中不存在），点击即 404。`BaseHead` 同时为这些页面生成同组 hreflang，搜索引擎也会收到 404。
   建议：Header 增加 `localeLinks={false}` 或按路由白名单隐藏语言键；`alternates()` 对非 `[...locale]` 路由返回空；这三页的 `<head>` 不输出 hreflang。

2. **`/music` 的四张内容卡仍是玻璃 + 28px 圆角。**
   `.jk-deck`、`.jk-lyr`、`.jk-list`、`.jk-juke` 都挂 `.glass`（`music.astro:69/194/203/227`），`player.css` 给 28px 圆角。这与 R44 写死的判据「内容=纸、浮层=玻璃」直接冲突；从首页点进音乐页，材质语言会突然换一套。
   建议：四张卡改 `.sheet` + 直角，玻璃只留给 MiniPlayer；唱盘/黑胶的物料色不受影响。

3. **`/admin` 是站内唯一没有跟上 R44 的页面。**
   `admin.css` 仍是 `.glass` 面板、`.box/.pane` 28px 圆角、`.key` 药丸、顶部 `top: 16px` 悬浮胶囊功能栏（`admin.css:40-47/185-197/338-342`）。公开面已经是通栏顶栏 + 直角纸面，后台还是上一版玻璃卡片堆。
   建议：后台功能栏改通栏或至少去掉圆角与悬浮偏移；面板改纸面；按钮改方框。后台是每天用的页面，语汇断层比公开页更磨人。

### 11.2 P2

4. **`--sp-10` 未定义，两处 margin 整条失效。**
   令牌表里只有 1/2/3/4/5/6/8/12/16/24/32；`tools/index.astro:85` 与 `tools/steps.astro:224` 直接写 `var(--sp-10)`（无 fallback），CSS 在计算值阶段判定整条声明无效，实际 margin 为 0。`tv.css`/`login.css` 用了 `var(--sp-10, 4rem)` 才有兜底。
   建议：补 `--sp-10: 2.5rem`，或两处改 `--sp-12`。

5. **`/tv` 播放器硬编码深色与金色。**
   `tv.css` 里 `#000`、`#08080a`、`#141416`、`#2a2a30`、`#f0b429` 等写死（683–798、1040–1091）。晨版下从米白纸面切进纯黑影院，金色也不属于四套版次的任一强调色。影院模式本身合理，但金色高亮与站点 `--press/--seal` 没有关系。
   建议：播放器保留黑底，把高亮色换成 `--seal`（或定义一个「影院金」物料色并注明不随版次）。

6. **浮动层没有统一的分层与避让表。**
   MiniPlayer 60、ChatDock 61、`/bushu` Toast 60、`/tv` Toast 100、`/tv` 播放器 90。窄屏下 ChatDock 靠 `--jk-room` 让开播放器，但 `/bushu` 的 Toast 没有让；`/tv` 的播放器会盖住 ChatDock（合理），Toast 又会盖住播放器（可能不合理）。
   建议：写一张浮层层级表，或统一到 60/70/80/90 四档；Toast 抬到播放器之上要在文档里说明。

7. **列表页没有分页。**
   `PAGE_SIZE = 10` 定义在 `consts.ts:20`，全站没有使用；`/posts`、`/notes`、`/projects` 全量渲染。现在 7 篇/2 篇/5 个没问题，内容涨到 100 篇时首屏 DOM 与滚动长度会线性变差。
   建议：要么删掉死常量，要么在 `getListItems` 之后切片并加「上一页/下一页」索引条（报纸语汇可用「续前版」）。

8. **版次菜单的键盘语义不完整。**
   `role="radiogroup"` + `role="radio"` 期望方向键切换与 roving tabindex，但实现里只能 Tab 逐个走、Enter 选择；Esc 关闭是有的。语言菜单则是普通链接组，没有 `role`。
   建议：二选一——要么补方向键，要么把版次菜单改成普通按钮组（去掉 radio 语义），让两个菜单行为一致。

### 11.3 P3

9. **5 个令牌当前无用户**：`--text-4xl`、`--sp-32`、`--header-h`、`--brass`、`--brass-lit`。前两个是尺度冗余，`--header-h` 与 `--header-offset` 重复表达顶栏高度（后者才是实际用户），`--brass` 两档在注释里已承认只剩物料组完整性。
10. **局部字号绕过 token**：`/bushu` 标题 `clamp(2.6rem, 8vw, 4rem)`、`/admin .box .title` 用 3xl、`/tv` 与 `/login` 用 3xl 但 fallback 写 2.25rem。读者感知不明显，维护时会出现「同一个页头标题三处不同来源」。
11. **无 `print` / `forced-colors` / `prefers-contrast` 适配。** 一套以报纸为隐喻的站点没有打印样式尤其可惜：现在打印会带上光晕、噪点、玻璃、浮动播放器与对话键。建议至少加一份 `@media print`：去背景、去浮层、正文黑字白纸、链接展开 URL。
12. **文档漂移**：`docs/设计改版.md` 自述「方向已定，尚未落地，站里一行样式都没改」，但当前构建产物已是 R44 对开大版。两份记录指向不同现实，后来者会先读错。
13. **页脚两组链接没有分组标题。** 宽屏靠 32px 间距能看出「站内/站外」，窄屏堆成两行后这层区分消失；「GitHub / 邮箱」与「归档 / 标签」看起来是同一组。
14. **首页右栏内容不足时留白。** 右栏固定取 3 条随笔，实际只有 2 条；左栏长列表结束时右侧会空出一大段（改版审计第 3 条问题的残留）。
15. **图库在索引面缺席。** 两组相册仍是 draft，`/photos` 只有空状态，`HIDDEN_SECTIONS` 又把它排除出归档；访客从首页目录点进图库会看到一句「还没整理好」。
16. **列表条目的元信息偏少。** 文章/随笔列表只有标题 + 日期；归档与标签页有「栏目」列，列表页没有。改版审计第 7 条（节奏单一）只解决了一半。

## 14. 结论

这套 UI 的身份很清楚：**一份会换版次的报纸，而不是一个套了报纸皮肤的网站。** 它的强度来自三条纪律：

1. 材质分工（纸 vs 玻璃）承担层次，不靠卡片边框；
2. 字号跨度（约 10 倍）承担层级，不靠颜色和阴影；
3. 两个强调色分工（黄铜=可点，朱红=刊物在说话），不混用。

最值得先处理的三件事，按顺序：**修掉中文专属页的语言切换 404**、**把音乐页与后台拉回同一套材质语汇**、**补一份打印样式**。前两件是「同一个站不该有两种长相」，第三件是这套报纸隐喻本来就该有、却还缺的一页。
