# 玻璃版 UI 规范（2026-10-23）

> 来源：`designprompts.dev` 的真实风格提示词（本机已提取的 30 份原文），主参照
> **Minimalist Dark**（`minimal-dark.json`：分层石板色、暖琥珀、玻璃卡、环境光、
> 大留白），辅参照 **Modern Dark**（环境光斑与微交互）与 **Monochrome**（字号层级、
> 克制用色）。不采用其默认色值，只采用结构与材质规则。

## 设计读法

个人长文博客，读者是来读文章与看作品的人；语言取「夜间的玻璃与暖光」，极简、
安静、有层次，不做营销页式的冲击。

- `DESIGN_VARIANCE: 5`（克制，非对称只用于首页头版）
- `MOTION_INTENSITY: 4`（淡入、悬停描边、环境光，不做大幅位移）
- `VISUAL_DENSITY: 3`（大留白，卡片之间 12–24px，章节 64–96px）

## 两条硬规则

1. **所有内容面都是玻璃卡**：半透明底 + 24px 模糊 + 1px 低透明度边 + 顶部受光。
   页面底色不再是「纸」，而是分层暗场 + 两团环境光。
2. **只有一套配色：门**（`portal`）：
   `#050505` 舞台 + `#fbfbfb` 白光 + `#c4ad97` 黄铜；单一强调色。
   版次切换器已移除；纸张/胶片/霓虹/夜玻璃四套全部移除。

## 材质配方

```css
background: rgba(var(--paper-c), 0.58);
backdrop-filter: blur(24px) saturate(160%);
border: 1px solid rgba(var(--ink-c), 0.10);
border-radius: 20px;
box-shadow:
  inset 0 1px 0 rgba(255,255,255,0.07),
  0 24px 64px -28px rgba(0,0,0,0.75);
```

悬停只允许：描边提亮 + 极轻的外发光（`0 0 32px rgba(196,173,151,.16)`），不做整卡上浮。

## 字号

Manrope（几何无衬线，自托管）+ 系统中文字体栈；等宽 IBM Plex Mono。
12 / 13 / 16 / 18 / 20 / 24 / 32 / 40 / 56，刊名 `clamp(2.75rem, 7vw, 5.5rem)`，
头条 `clamp(1.75rem, 3.5vw, 2.75rem)`。正文 17px / 1.85。

## 圆角

8 / 12 / 20 / 28 / 999。卡片 20，输入与按钮 12，药丸 999。全站统一。

## 移除的报纸语汇

- 朱红 5px 报头线 → 1px 渐隐玻璃线
- 竖排栏目标识 → 横向玻璃小标签
- 直角纸面 → 玻璃圆角卡
- 宋体大刊名 → Manrope 几何标题
- 分栏线 → 卡片间距
